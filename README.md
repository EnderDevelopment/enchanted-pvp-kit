# EnderDev PvP Kit Mod

A Minecraft mod for Fabric loader that provides a PvP kit with all items enchanted. This mod is designed for players who enjoy competitive PvP gameplay, offering a comprehensive set of enchanted items to enhance their combat capabilities. The mod includes a diamond sword, bow, and full diamond armor, all with powerful enchantments to give players an edge in battles.

## Install

1. Install the Fabric loader for Minecraft 1.20.4.
2. Place the mod jar in the `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Use

1. Launch Minecraft with the Fabric profile.
2. Use the command `/pvpkit` to receive a PvP kit with enchanted items.
